Identity Hierarchy

Configure how the CDP resolves and merges customer identities across data sources. Tier 1 identifiers create permanent merges; Tier 2 merges only before account creation; Tier 3 identifiers are tracked but never used to merge profiles.

Technical Admin only. Changing identity merge rules affects how customer profiles are consolidated. Incorrect configuration can lead to profile merges or splits that are difficult to reverse. Coordinate with the Data team before making changes.

Permanent — Profiles are always merged when this identifier matches. Suitable for official government-issued IDs and permanent account numbers.
