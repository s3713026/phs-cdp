Design System

The foundational component library for the PHS Customer Data Platform. Every CDP module is built from the primitives on this page — colors, type, spacing, and the interactive components below. Modules should never introduce a one-off button, badge, or table style outside this system.

Deep PHS Green as primary, PHS Gold as a sparing brand accent, neutral surfaces for most of the UI. Sampled from assets/logo.webp — not invented.

Navigation

The dark sidebar and light topbar framing this very page are the real Sidebar/Topbar components — not a mockup.

The sidebar renders from js/data/nav-items.js — the same data every future module page will import. Nothing about the sidebar markup changes when Dashboard, Customers, etc. are built; only the data's current flag moves.
